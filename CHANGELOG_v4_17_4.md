# LuxDot v4.17.4 — Challenge Layer + Open Knowledge

- Added universal `Challenge · Correct / اعترض · صحّح` controls to substantive content blocks.
- Every correction carries page URL, passage anchor, quoted claim, correction type, counter-source and reproducibility note into a prefilled GitHub issue.
- Added correction categories for factual errors, inference challenges, weak sources, broken links, bugs, translation/accessibility, conflicts/duplicates and improvements.
- Added private security-report route through GitHub Security Advisories; security issues are not encouraged into public issues.
- Added persistent `Correct LuxDot` troubleshooting entry across the site.
- Added `corrections.html` as a unified review/troubleshooting hub.
- Added `open-knowledge-covenant.html`.
- Updated LuxDot philosophy/method pages with falsifiability, correction and open-knowledge principles.
- Explicitly distinguishes LuxDot-authored/open materials from third-party works that retain their own licenses/rights.
