أطروحة البحث 002

نبدأ من واقعة قابلة للدحض: لا يوجد دليل تاريخي موثوق أن اسم جافا سكريبت (JavaScript) أُخذ من الخط الجاوي (Aksara Jawa) أو من إيمان جزيرة جاوا. ثم نسير بالعكس: جافا سكريبت (JavaScript) ← جافا (Java) ← القهوة ← جاوة، وبالتوازي نفتح خطاً آخر: يونيكود (Unicode) ← الخط الجاوي (Aksara Jawa) ← مخطوطات سيرات/سلوك/باباد ← طبقات جاوية قديمة وإسلامية. القيمة ليست في ادعاء «شفرة خفية»، بل في أن المصادفة اللفظية تستطيع أن تصبح أداة لاسترداد ذاكرة حقيقية إذا بقي المصدر أقوى من الرمز.

Research thesis 002

We begin with a falsifiable statement: there is no reliable historical evidence that the name JavaScript was derived from Aksara Jawa or from the religious traditions of Java. The documented route is JavaScript ← Java ← coffee culture ← Java as a place-name. In parallel, another route matters: Unicode ← Aksara Jawa ← serat, suluk and babad manuscripts ← older Javanese and Islamic layers. The value is not a “hidden code” claim; it is the possibility that a verbal coincidence can lead back to real cultural memory when sources remain stronger than symbols.

DOCUMENTED

JavaScript is a separate language

Brendan Eich created the language at Netscape in 1995. ECMA-262 records its standardisation as ECMAScript. Similarity of names does not make Java and JavaScript one technical lineage.

DOCUMENTED

Aksara Jawa is digitally encoded

Unicode assigns the Javanese block U+A980–U+A9DF and documents technical shaping requirements for the script.

LUXDOT READING

Java + Script

A later literal reading, not a historical etymology. We use it as a research doorway: can the web help put the writing traditions of Java back into circulation?

METHOD

No text without a layer

Jayabaya, Ratu Adil and Sabdo Palon are not one source. Version, date, copyist, language and historical context must be identified before interpretation.

The living laboratory

Four lenses organise the investigation. Each changes the question, not the standard of proof.

Name tree

Java · island and geographic nameThe name predates programming by centuries; even its older etymology requires careful separation of Indian, local and later sources.
Java · coffeeThe island became a global name for coffee through commercial and Dutch-colonial history; this is part of how the word travelled.
Java · programming languageThe Oak/Green project was renamed Java in the 1990s. The cultural bridge to the island runs through coffee, not Aksara Jawa.
LiveScript → JavaScriptNetscape changed the name in the context of Java’s popularity, while JavaScript remained a technically different language.
Java.Script · LuxDotOnly here begins the artistic reading: the dot lets “script” mean writing/text as well as code, without pretending that this was the historical intention.

Java is not “one religion”

Hindu-Buddhist layers

Kingdoms, kakawin, temples and Sanskrit vocabulary.

Islamic layers

Wali Songo, pesantren, suluk and Pegon traditions.

Kejawen

An umbrella for diverse practices and meanings, not a single church or canonical book.

Modern plurality

Christianity, local customs, the Indonesian state, education and national-language identity all reshape the field.

LuxDot rule: overlap does not prove a single origin, and continuity does not prove that meaning stayed unchanged.

Serat Centhini · a knowledge node

Rather than calling it a “holy book of Java,” this research places Serat Centhini where the evidence is strongest: a vast early-nineteenth-century courtly literary and cultural encyclopaedia. It gathers social, religious, bodily, musical, travel and spiritual knowledge. Studies published through Indonesia’s National Library document Islamic and Sufi concepts alongside Javanese and Hindu vocabularies. This does not prove a single religion; it documents a society recomposing meaning from multiple layers.

The Netherlands axis · memory and power

The word Java reached Europe through coffee and colonial trade; Javanese texts also travelled through collecting, scholarship and transfer to European institutions. Digitisation is therefore not enough by itself. We ask who owns the original, who described it, in which language it was catalogued, and who can access it now. The British Library’s Javanese digitisation work shows how access can be reopened, while Arabic–Javanese and interlinear manuscripts reveal a knowledge history more complex than an East/West binary.

DIGITAL ETHICS

Digitisation and renewed access

A digital copy does not restore physical ownership, but it can lower barriers when accompanied by local description, translation, context and community participation.

OPEN QUESTION

Who describes memory?

Colonial or external cataloguing can preserve material while reshaping its meaning. Institutional and local descriptions should be shown side by side where possible.

LuxDot verification protocol

Define the claim

One testable sentence, not a general feeling that a text resembles the present.

Find the earliest witness

Manuscript, critical edition, institutional catalogue or reliable philological study.

Separate versions

Do not merge historical Jayabaya with a nineteenth-century text or a modern social-media quotation.

Test translation

The original Javanese word, its context and semantic range matter more than a dramatic translated phrase.

Seek counter-evidence

Ask what evidence would weaken the hypothesis, and look for it seriously before publication.

Assign confidence

Documented / probable / possible / tradition / symbolic / unverified / rejected — and revise downward when needed.

Onderzoeksthese 002

We beginnen met een falsifieerbare stelling: er is geen betrouwbaar historisch bewijs dat de naam JavaScript is afgeleid van Aksara Jawa of van de religieuze tradities van Java. De gedocumenteerde route is JavaScript ← Java ← koffiecultuur ← Java als plaatsnaam. Parallel loopt een tweede relevante route: Unicode ← Aksara Jawa ← serat-, suluk- en babadmanuscripten ← oudere Javaanse en islamitische lagen. De waarde ligt niet in een claim over een “verborgen code”, maar in het vermogen van een woordelijke toevalligheid om ons terug te leiden naar echte culturele herinnering, zolang de bron sterker blijft dan het symbool.

GEDOCUMENTEERD

JavaScript is een zelfstandige taal

Brendan Eich maakte de taal in 1995 bij Netscape. ECMA-262 documenteert de standaardisering als ECMAScript. De gelijkenis in naam maakt Java en JavaScript technisch niet tot één oorsprong.

GEDOCUMENTEERD

Aksara Jawa is digitaal gecodeerd

Unicode reserveert voor het Javaanse schrift het blok U+A980–U+A9DF en documenteert technische regels voor lettervorming en tekens.

LUXDOT-LEZING

Java + Script

Een latere letterlijke lezing, geen historische etymologie. We gebruiken haar als onderzoeksvraag: kan het web helpen om het schrift van Java opnieuw in omloop te brengen?

METHODE

Geen tekst zonder laag

Jayabaya, Ratu Adil en Sabdo Palon vormen niet één bron. Versie, datum, kopiist, taal en context moeten worden vastgesteld vóór interpretatie.

Serat Centhini · kennisknooppunt

In plaats van Serat Centhini een “heilig boek van Java” te noemen, plaatsen we het waar het bewijs het sterkst is: als een omvangrijke literaire en culturele encyclopedie uit de hofwereld van het begin van de negentiende eeuw. Het werk verzamelt sociale, religieuze, lichamelijke, muzikale, reis- en spirituele kennis. Studies via de Nationale Bibliotheek van Indonesië documenteren islamitische en soefistische begrippen naast Javaanse en hindoeïstische woordenschat. Dat bewijst geen enkele verenigde religie; het documenteert een samenleving die betekenis uit meerdere lagen samenstelde.

Nederland-as · herinnering en macht

Het woord Java bereikte Europa via koffie en koloniale handel; Javaanse teksten reisden eveneens via verzamelen, studie en overdracht naar Europese instellingen. Digitalisering alleen is daarom niet genoeg. We vragen wie het origineel bezit, wie het heeft beschreven, in welke taal het is gecatalogiseerd en wie er vandaag toegang toe heeft. Het digitaliseringswerk van de British Library laat zien hoe toegang kan worden heropend, terwijl Arabisch-Javaanse en interlineaire manuscripten een kennisgeschiedenis tonen die ingewikkelder is dan een simpele tegenstelling tussen Oost en West.
