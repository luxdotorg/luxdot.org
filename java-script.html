النتيجة المركزية

لا يوجد دليل تاريخي معروف أن JavaScript سُمّيت تيمناً بكتابة جاوا أو إيمان الجزيرة. JavaScript وُلدت في Netscape سنة 1995، وكان اسم LiveScript مستخدماً قبل JavaScript؛ تغيير الاسم ارتبط بسياق شعبية Java. أما Java فقد انتقلت من Oak إلى اسم مرتبط بقهوة Java. لذلك الصلة بجزيرة جاوا حقيقية ولكنها غير مباشرة، بينما قراءة JAVA + SCRIPT بوصفها «كتابة جاوا» قراءة لغوية/فنية لاحقة وليست أصل التسمية.
