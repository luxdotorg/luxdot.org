# LuxDot v4.3.74

Built from v4.3.73 only.

- Safe language-link propagation now preserves relative folders instead of flattening paths.
- Removed whole-page visibility hiding during language bootstrap to prevent blank pages.
- Java Script research now has explicit Arabic, English and Dutch locale panels with equivalent research structure and source register.
- Arabic Java Script typography is explicitly locked to the LuxDot Kufi stack.
- Nusantara Java Script research cartridge is localized in AR/EN/NL.
- Living Memory data is loaded deterministically before its renderer, with a retry fallback instead of an endless loading state.
- No changes to Reiderland or Care Circle map implementations from v4.3.73.
