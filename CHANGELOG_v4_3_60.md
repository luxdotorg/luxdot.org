# LuxDot v4.3.60

- Added a dedicated Rasāʾil al-Ḥikma library reader.
- Library book now opens the reader instead of the research dossier.
- Reader loads the public Internet Archive OCR layer when available, supports full-text search and automatic heading extraction.
- Added direct jumps for al-Ghayba, Manshur al-Ghayba, al-Qaʾim al-Muntazar, Wali al-Zaman and Kashf al-Haqaʾiq.
- Added a source-image mode using the Internet Archive embedded scan so quotations can be checked against page images.
- Kept LuxDot research/interpretation separate from the source reader.
- Added explicit OCR reliability warning.
