# LuxDot information architecture v4.4.1

## Primary concepts
- LIVE RESEARCH / الأبحاث الحيّة — research is a changing evidence graph, not a static archive.
- SIGNAL / الإشارة — replaces the generic “Media”. It is the project’s observation/dispatch surface: current events, field signals, media, evidence streams.
- VALUES / القيم — a separate Values Tree, not mixed into Praxis.
- PRAXIS / المناهج — methods and practices: how people act.
- MEMORY / الذاكرة — remembrance and human loss.
- PULSE / النبض — transparent operational status, traffic, changes, Now/Next.

## Why SIGNAL
“Telescope” and “News Observatory” describe an instrument or newsroom. SIGNAL describes the thing LuxDot detects, verifies, routes, and connects. Internally the Signal page can later have lenses: LIVE / WORLD / LOCAL / FIELD / EVIDENCE / MEDIA.

## Values Tree
The tree is deliberately pluralistic. Values are nodes with tensions and compatibilities, not commandments. Next iteration should add cross-cultural provenance, conflict edges, anti-values/shadows, and observable behaviors.
