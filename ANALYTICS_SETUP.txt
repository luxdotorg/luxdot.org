LuxDot Analytics Setup — v2.7.3

Recommended: Cloudflare Web Analytics

What is already added
- analytics-config.js
- analytics.js
- Both are included on every HTML page in this package
- Tracking stays OFF until you paste your own token
- No visible UI is added to the website

To activate Cloudflare Web Analytics
1. Sign in to Cloudflare
2. Open Web Analytics
3. Add luxdot.org
4. Open Manage site
5. Copy the site token from the JavaScript snippet
6. Open analytics-config.js
7. Paste the token here:
   cloudflareToken: "YOUR_TOKEN"
8. Keep:
   provider: "cloudflare"
9. Upload the edited analytics-config.js to the repository root

If luxdot.org is proxied through Cloudflare (orange cloud), Cloudflare can also enable Web Analytics automatically without a manual beacon. In that case, you may leave the token empty to avoid double counting.

Optional GA4
- Set provider to "ga4"
- Paste your Measurement ID such as G-XXXXXXXXXX into ga4MeasurementId

Verification
Open the browser console and run:
luxdotAnalyticsStatus()

Expected after activation:
{ active: true, ... }

Important
Do not use both Cloudflare automatic injection and the manual Cloudflare token at the same time, because that may duplicate measurements.
