LUXDOT / LIVING RESEARCH 004 / JAVA.SCRIPT
Date: 11 August 2026
Base website: LuxDot v2.8.0

THESIS
The historical chain and the symbolic reading are deliberately separated.
Verified: JavaScript emerged at Netscape in 1995; JavaScript and Java are distinct languages. Javanese (Aksara Jawa) is a Brahmi-derived script encoded at Unicode U+A980–U+A9DF. Javanese manuscript traditions long predate computing.
Interpretation: reading JAVA + SCRIPT literally as “Java script” is an after-the-fact LuxDot creative bridge, not evidence that the language name encoded Javanese religion, prophecy, or manuscripts.

RESEARCH TREES
1. Name: island -> coffee -> Java language -> JavaScript -> LuxDot reinterpretation
2. Writing: Old Javanese/Kawi -> lontar/manuscripts -> Aksara Jawa/Pegon -> print/romanisation -> Unicode -> web
3. Belief: Hindu-Buddhist layers -> Islam/Wali Songo/Pegon/Suluk -> Kejawen plurality -> modern religious plurality
4. Prophetic-political: Jayabaya / Ratu Adil -> textual dating -> variant comparison -> political reception -> disconfirming evidence
5. Colonial/archive: Dutch trade/colonial power -> collecting/archives -> digitisation -> ethical return of access/context

EVIDENCE RULE
Verified / probable / possible / tradition / symbolic / unverified / rejected.
No contemporary person or event is treated as fulfillment merely from resemblance.

CREATIVE OUTPUT
“The Living Script”: JavaScript is not presented as a prophecy about Java. Instead, the web language becomes a tool through which Javanese script and memory can become searchable, interactive, and accessible again.
