# Governance v1 Scope

Included: repository policy, risk classification, PR workflow, static QA, credential checks, contribution guidance, release/rollback guidance, content-integrity labels and documented branch-protection intent.

Excluded: production runtime refactors, Cloudflare changes, DNS changes, Supabase changes, content migrations, legacy file cleanup and automated production merge policy.

Keeping these excluded from v1 limits blast radius and makes the governance change easy to review and revert.
