# LuxDot Social Return Pledge --- Draft

LuxDot asks organizations and individuals who derive meaningful
commercial value from LuxDot's openly shared work to return part of that
value directly to humanity.

LuxDot itself does not receive or hold those funds.

Suggested practice: 1. choose a credible independent humanitarian,
educational, cultural, scientific, environmental, or public-benefit
organization; 2. contribute directly to that organization; 3. where
appropriate, publish the recipient and amount/percentage for
transparency; 4. do not imply that LuxDot endorses a product merely
because a contribution was made; 5. preserve attribution and provenance
of LuxDot-derived material.

This is a voluntary stewardship pledge unless a separate written
partnership agreement states otherwise.
