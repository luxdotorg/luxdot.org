# LuxDot Governance

Governance v1 consists of:

- `/GOVERNANCE.md` — core repository policy and risk classes.
- `/CONTRIBUTING.md` — development and PR workflow.
- `/VERSION` — canonical human-readable release identifier.
- `AUTONOMY_POLICY.md` — safe boundary for routine autonomous development.
- `RELEASE_POLICY.md` — release and rollback rules.
- `BRANCH_PROTECTION.md` — intended GitHub protection settings for `main`.
- `QA_NOTES.md` — scope and limitations of automated checks.
- `/.github/workflows/` — automated QA/credential checks.
- `/.github/pull_request_template.md` — risk-aware PR template.

Governance should evolve through reviewed pull requests rather than undocumented changes to production practice.
