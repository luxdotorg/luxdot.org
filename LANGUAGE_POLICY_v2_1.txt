LUXDOT LANGUAGE POLICY — CURRENT

SITE UI
1. Arabic (AR) — primary/default language
2. English (EN) — global secondary language
3. Dutch (NL) — available where practical/relevant
Spanish and Hebrew are not currently shown as site UI languages.

RELIGIOUS / SOURCE TEXTS
The UI language limit does not restrict original-source presentation.
For any religious/source passage, use no more than three languages, selected as needed from:
- the reader's native language
- the source's original/native language
- a language shared by reader and source

Use only the languages that improve understanding. Original Hebrew, Greek, Latin, Arabic,
Dutch, or other source languages may therefore appear where relevant without becoming
global site-interface languages.
