استوديو نقطة نور

هذه الصفحة هي لوحة التشغيل والإعداد. بيانات البث السرية لا تُحفظ في GitHub ولا داخل الموقع العام.

🎙️ من الميكسر إلى العالم

1. المايكروفونات والأجهزة → الميكسر.
2. خرج USB أو Audio Interface → الكمبيوتر.
3. برنامج ترميز صوتي مثل Mixxx أو BUTT/برنامج بث متوافق → خادم البث.
4. خادم Icecast/AzuraCast أو خدمة متوافقة → رابط استماع عام ثابت.
5. LuxDot يشغّل الرابط العام، بينما اسم المستخدم/كلمة مرور الـDJ تبقى على جهاز الاستوديو فقط.

🔴 التحويل إلى المباشر

المعماريّة المفضلة: رابط استماع واحد ثابت. الـAutoDJ يشغّل الجدول اليومي؛ عندما يتصل الاستوديو بحساب DJ يأخذ البث الحي الأولوية، وعند قطع الاتصال يعود الجدول تلقائياً.

النتيجة: المستمع لا يحتاج لتحديث الصفحة ولا لتغيير زر التشغيل.

🔐 ما لا يوضع في الموقع

ممنوع حفظ كلمة مرور الـDJ، مفتاح الـsource، أو بيانات لوحة إدارة الخادم داخل ملفات GitHub العامة.

الملف radio-live-config.js يحتوي فقط على رابط الاستماع العام وحالة التشغيل.

🎚️ إعداد صوت مقترح

بث كلام/موسيقى: Stereo، 44.1 أو 48 kHz. اختر bitrate مناسباً لاتصالك والخادم، واضبط الميكسر بحيث لا يصل الكلام أو الموسيقى إلى clipping. استعمل سماعات مراقبة قبل فتح المايك على الهواء.

قبل أول بث

بعد اختيار خادم البث نحط رابط الاستماع العام هنا:

window.LUXDOT_RADIO_STREAM.streamUrl = 'https://…/stream';

ثم يتصل برنامج الاستوديو بعنوان الـingest وكلمة مرور DJ التي يعطيها الخادم. هذه البيانات تبقى محلياً عندك.

حقوق الموسيقى

وجود اسم فنان في الجدول لا يعني أن ملفه يمكن بثه تلقائياً. الأغاني التجارية تُفعّل فقط عندما تكون حقوق البث/الترخيص متوفرة. إلى ذلك الحين يبقى الاسم كخانة تحريرية ويستخدم النظام مواد مسموحة فقط.
